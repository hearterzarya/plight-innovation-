# PLIGHT Innovation

AI-powered wildlife safety technology for smarter villages — marketing site built with Next.js App Router.

## Routes

- `/` — Homepage overview
- `/about` — Mission, challenge, team, vision
- `/solutions` — Products and deterrent systems
- `/technology` — AI monitoring and engineering
- `/impact` — Deployment stats and government partners
- `/field-trials` — Jim Corbett trials and validation
- `/resources` — Specifications, brochure, FAQs
- `/contact` — Inquiry and partnership CTAs

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run lint
npm run build
npm start
```

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
